# LegendWeapon 1.0.0
Paper 1.21.x plugin by Shadow Craft.

Features:
- Death Note custom weapon.
- Basic attack: 7 + 5 damage per kill streak.
- Dash: right click, 10 blocks, 15s cooldown, unlock at 3 kills.
- Phoenix: Shift + right click, target up to 10 blocks, 37 damage, 32s cooldown, unlock at 5 kills.
- Chain Bind: Shift + left click, up to 5 targets in front within 32 blocks, 2 damage every 0.2s for 5s, unlock at 7 kills.
- Ultimate: Shift + left click, 8-block area, 25 damage, 60s cooldown, unlock at 10 kills.
- Kill streak and bonus damage reset on death.
- Vanilla particles/sounds are used; ModelEngine is not required.

Build with Java 21:
mvn clean package

Command:
 /legendweapon give
